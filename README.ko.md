# Video Toolkit

동영상을 볼 때 쓰는 크롬 확장 프로그램입니다. 대부분의 동영상 사이트에서 동작합니다.

[English](README.md)

## 기능

영상 위에 마우스를 올리면 버튼이 나타납니다.

- 속도: `−`, `+`로 0.1배씩 바꿉니다. 속도 숫자를 누르면 0.25배부터 2배까지 고를 수 있습니다.
- PiP: 브라우저의 화면 속 화면 창을 엽니다.
- 자막 PiP: 영상과 자막을 항상 위에 떠 있는 작은 창으로 엽니다. 창에서 재생/일시정지, 10초 앞뒤 이동, 속도 조절을 할 수 있습니다. 자막은 넷플릭스, 유튜브, 그리고 브라우저 기본 자막을 쓰는 사이트에서 나옵니다. 다른 사이트에서 끼워 넣은 영상에서는 쓸 수 없습니다.

## 설치

1. [Releases](../../releases/latest)에서 `video-toolkit-<버전>-chrome.zip`을 받아 지우지 않을 폴더에 압축을 풉니다.
2. `chrome://extensions`를 열고 개발자 모드를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 누르고 압축을 푼 폴더를 고릅니다.

업데이트할 때는 새 버전을 같은 폴더에 풀고 확장 프로그램 카드의 새로고침 버튼을 누릅니다. 설치하거나 업데이트한 뒤에는 열려 있던 동영상 탭을 새로고침합니다.

## 개발

Node.js 22 이상이 필요합니다.

```sh
npm install
npm run dev
```

`.output/chrome-mv3-dev` 폴더를 "압축해제된 확장 프로그램"으로 불러옵니다. `npm run dev`가 켜져 있는 동안에는 코드를 고치면 자동으로 다시 불러옵니다.

- `npm run build`: 배포용 빌드 (`.output/chrome-mv3`)
- `npm run zip`: 배포용 zip (`.output`)
- `npm run check`: 타입 검사
